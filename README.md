> Um dashboard full-stack completo para acompanhamento de aprendizado e registro de histórico de estudos.

🌐 **Acesse o projeto em produção:** [DevTrack (Deploy na Vercel)](https://dev-track-one-eta.vercel.app/)

O **DevTrack** nasceu da necessidade de centralizar a organização acadêmica e o desenvolvimento pessoal. Com ele, é possível gerenciar rotinas de estudo, monitorar o progresso em diferentes matérias e ter uma visão clara do seu painel de aprendizado através de um sistema seguro com autenticação.

---

## ✨ Funcionalidades

- 🔐 **Sistema de Autenticação:** Login seguro para usuários utilizando JWT (JSON Web Tokens).
- 📊 **Dashboard de Aprendizado:** Interface integrada e intuitiva para visualização do progresso.
- 📚 **Histórico de Estudos:** Registro e acompanhamento das sessões de estudo.
- 🔄 **Integração Total:** Comunicação fluida entre a interface do usuário (Frontend) e o servidor (Backend).

---

## 💻 Tecnologias Utilizadas

O projeto foi desenvolvido consolidando conceitos de desenvolvimento web, orientação a objetos e bancos de dados, utilizando as seguintes tecnologias:

### 🎨 Frontend
- **[React](https://reactjs.org/)** - Biblioteca JavaScript para construção da interface.
- **[Vite](https://vitejs.dev/)** - Ferramenta de build super rápida.
- **[React Router DOM](https://reactrouter.com/)** - Navegação e roteamento da SPA (Single Page Application).
- **[Lucide React](https://lucide.dev/)** - Pacote de ícones limpos e modernos.

### ⚙️ Backend
- **[Node.js](https://nodejs.org/)** - Ambiente de execução do servidor.
- **[Express](https://expressjs.com/)** - Framework minimalista para lidar com rotas e middlewares.
- **[JWT (JSON Web Token)](https://jwt.io/)** - Autenticação segura de usuários.

### 🗄️ Banco de Dados & Infraestrutura
- **SQLite / [Turso](https://turso.tech/)** - Banco de dados leve e eficiente, adaptado para edge computing.
- **[Docker](https://www.docker.com/) & Docker Compose** - Containerização da aplicação para fácil configuração.
- **[Vercel](https://vercel.com/)** - Hospedagem e deploy contínuo da aplicação.
